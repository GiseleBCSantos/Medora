# 🩺 Medora

Medora is a healthcare management platform designed to handle medical appointments, clinical workflows, and patient interactions in a scalable and production-oriented way.

This project was designed with a **documentation-first** approach, focusing on strong domain modeling, clear separation of responsibilities, and real-world healthcare scenarios.

---

## 🎯 Project Purpose

- Manage appointments, procedures, and clinical agendas
- Support multiple healthcare roles with strict RBAC
- Handle payments, refunds, and attendance flows
- Maintain clinical records and medical documents
- Serve as a robust academic and professional portfolio project

---

## 👥 User Roles

- **Patient** – Schedules appointments, performs payments, accesses documents
- **Doctor / Health Professional** – Performs consultations and clinical records
- **Secretary / Attendant** – Manages agendas, approvals, and daily operations
- **Clinic Administrator** – Configures clinic rules, procedures, and policies

---

## 🧱 High-Level Architecture

- **Backend:** Django + Django REST Framework
- **Frontend:** React (Vite or Next.js)
- **Database:** PostgreSQL
- **Authentication:** JWT
- **Deployment:** Docker (Backend) + Vercel (Frontend)
